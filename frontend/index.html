Auth & Frontend Architecture

Zero-Build Frontend: Tailwind Play CDN, Firebase SDK CDN, and Alpine.js.

Global Auth Store: Managed via $store.auth and Firebase Auth (emulator port 9099 locally).

Token Injection: Handled by apiFetch(), passing fresh Bearer ID tokens to FastAPI.

Protected Backend: FastAPI validates JWTs via Firebase Admin SDK with strict Tach boundaries.

Authentication Required

The /api/ping endpoint requires a valid Google Firebase Bearer token. Sign in with Google above to send authenticated requests.

FastAPI Backend Ping

Submits a message to Cloud Run / FastAPI, which enforces token authentication and persists the ping with your user ID.
